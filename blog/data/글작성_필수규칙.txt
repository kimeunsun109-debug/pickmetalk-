SuN 블로그 글 작성 — 필수 내용 규칙
================================

## 원칙
아이디어 한 줄(`블로그글 아이디어.md`)에 적힌 **요점**을 먼저 읽고, 그 내용이 본문에 **반드시** 들어가야 합니다.

## 자동 인식 (blog_idea_requirements.py)

| 아이디어 패턴 | 글에 꼭 넣을 것 |
|--------------|----------------|
| 「현재 응모」「공모전」「뭐가 있지」 | **지금 마감 전인 공모전 이름·주최·마감일** 목록 (5건+) |
| 「후기」「써봤」 | 장점 + 단점 섹션 |
| 괄호 `(장점: … 단점: …)` | 괄호 안 키워드 본문 반영 |
| 「활용법」 | 왜 쓰는지 + 실사용 방법 |
| 「해결방법」「어떻게」 | 단계별 해결책 3가지 이상 |
| 「왜」「이유」 | 원인·배경 설명 |

## 동적 수집 (blog_live_content.py)
- AI 공모전 글: wevity에서 마감 전 공모 수집 → `{dynamic_ai_contests}` 블록
- 수집 실패 시: `data/contest_seed.json` fallback

## 검증
글 저장 전 `validate_post_html` + `validate_quality` 실행 — 누락 시 생성 중단 + 로그

## 품질 기준 (blog_post_quality.py) — Premium v3
- 본문 **최소 2,000자** (권장 **2,500자+**), 이미지 **4~8장**, 소제목 **4개 이상**
- 경험·체감 표현 2개 이상, 장점/단점·주의·팁·FAQ 포함
- AI 문체 금지 (「먼저」「다음으로」「결론적으로」 등 연결어 남발 X)
- 이미지: 스마트폰 촬영 느낌 (`blog_image.py` + `shot` 타입)
- 상세: `data/블로그_품질_가이드.md`

## 템플릿 추가 시
`POSTS_DB`에 `must_include`로 보강 가능:
```python
"must_include": {"dynamic_blocks": ["ai_contests"], "min_list_items": 5}
```
