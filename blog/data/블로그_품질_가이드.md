# SuN 네이버 블로그 품질 가이드

참고 스타일: https://blog.naver.com/hsrw1011/224339554395

## 1. 분량·정보량 (최우선 — Premium v3)
- **최소 2,000자** (자동 검증), **권장 2,500~4,000자**
- 단순 설명 X → 실제 사용 경험처럼
- 소제목으로 가독성 확보
- 처음~끝 하나의 스토리로 연결
- 이유·원리까지 설명
- 장점 + 단점 + 주의사항 + 팁 포함
- 광고/AI 느낌 금지

## 2. SEO
- 핵심 키워드 자연스럽게 반복
- 연관 키워드 활용
- 제목·본문 키워드 일치
- 소제목(H2 수준) 활용

## 3. 글 구성
① 도입 — 공감·문제·오늘 얻을 내용  
② 본문 — 개념·특징·장단점·활용·선택팁·FAQ·비교·후기형 설명  
③ 마무리 — 핵심 정리·추천 대상·개인 의견

## 4. 사람이 쓴 느낌
- "~해봤습니다", "~생각보다", "~처음에는", "~직접 사용하면서" 등 다양하게

## 5. 이미지 (4~8장)
- 스마트폰/미러리스로 찍은 듯한 자연스러운 사진
- 과도한 완벽 구도·HDR·과포화·플라스틱 질감 금지
- 대표·사용장면·디테일·비교·활용·생활·마무리 등 구도 다양화

## 자동 검증 (`blog_post_quality.py`)
- 2000자+ 필수, 2500자+ 권장(미달 시 경고), 이미지 4장+, 소제목 4개+, 경험 표현 2개+
