# 네이버 블로그 댓글 자동화 구조

## 모듈

| 파일 | 역할 |
|------|------|
| `naver_comment.py` | 댓글 전용 — URL 파싱, 3단 전략, 결과 로그 |
| `naver_blog_automation.py` | 방문·하트·이웃신청 — `CommentWriter` 호출 |

## 데이터 흐름

```
이웃글 URL
  → CommentContext (blogId, logNo 추출)
  → CommentWriter.write(문장)
  → 전략 1~3 순차 시도
  → CommentResult + naver_comment_log.jsonl
```

## 전략 (우선순위)

1. **mobile_cbox** — `m.blog.naver.com/CommentList.naver?blogId=&logNo=`
   - placeholder 가로채기 회피 → JS로 `#naverComment__write_textarea` 입력
2. **desktop_js** — PC 글 페이지 mainFrame + jQuery 클릭
3. **desktop_cbox** — cbox iframe (레거시)

## 로그

- `logs/naver_comment_log.jsonl` — 댓글 시도별 strategy/ok/error
- `logs/naver_visit_log.jsonl` — 방문+하트+댓글 통합

## 실행

```bat
:: 댓글 1건 테스트
python naver_blog_automation.py --mode test-comment --url "https://blog.naver.com/아이디/글번호"

:: IT 이웃 전체 방문 (댓글+하트)
python naver_blog_automation.py --mode visit-it-all

:: 오늘 partial 재시도
python naver_blog_automation.py --mode retry-partial
```

## 댓글 문장

`data/이웃댓글_상황별문장.xlsx` — 상황·키워드 매칭 후 `pick_comment()` 선택
