## A. 사용자 불편 / 개선 (코드·플로우 기반)

| # | 제안 | 근거 | 우선 |
|---|------|------|------|
| A1 | **설정에서 프로필 수정** (닉네임·MBTI·관심사) | 가입 시만 수집, `SettingsClient`에 편집 UI 없음 | 📋 |
| A2 | **재방문 환영 오버레이 연결** | `AbsenceWelcome` + `useAbsenceEvent` 구현됐으나 `ChatScreen` 미연결 | 📋 MVP |
| A3 | **일일 메시지 한도 실제 적용** | `canSendMessage()` 있으나 `/api/chat`에서 미검사 | 📋 MVP |
| A4 | **프리미엄 모달 → 실제 결제 전 안내** | `alert("준비 중")` — 베타에선 "한도 도달" UX만이라도 명확히 | 📋 |
| A5 | **캐릭터 카드에 실사 썸네일** | 현재 이니셜 원형만 표시 (`CharacterCard`) | 🌟 (이미지 준비 후) |
| A6 | **채팅 목록 빈 상태 가이드** | 첫 사용자가 "어디서 대화?" 헷갈릴 수 있음 | 💡 |
| A7 | **삭제 전 확인 모달 통일** | 대화 삭제·전체 삭제·계정 삭제 문구/패턴 일관성 | 💡 |
| A8 | **오프라인/네트워크 끊김 토스트** | 스트리밍 중 실패 시 재시도 버튼 | 📋 |
| A9 | **키보드·safe-area** (모바일) | iOS 하단 입력창·노치 — `viewport-fit=cover`는 있음, 실기 테스트 필요 | 💡 |
| A10 | **다른 기기 로그인 알림 문구 다듬기** | `DeviceSessionGuard` — 비개발자에게 이해 쉬운 카피 | 💡 |
