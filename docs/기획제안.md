## 후속 로드맵

1. **Web Push** — VAPID, service worker, rich notification (사진 썸네일)
2. **사진 대량 생성** — 캐릭터별 1000장, fingerprint 중복 제거
3. **대화 분위기 반영** — 최근 채팅 톤으로 시나리오 가중치
4. **7일/30일 리텐션 대시보드** — `photo_push_deliveries` 집계 뷰
5. **캐릭터 말투** — 시나리오별 character overlay (유나/나린 등)
