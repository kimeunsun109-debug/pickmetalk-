## i18n 구현 원칙 (모든 Phase 공통)

1. **UI 문자열:** 하드코딩 금지 → `messages/{locale}.json` 키
2. **캐릭터 데이터:** `nameKey`, `taglineKey`, `greetingKey` (값은 ko에 매핑)
3. **LLM:** `locale` 파라미터로 system prompt 분기 (Phase 3)
4. **날짜/숫자:** `Intl` + locale 인자
5. **URL:** Phase 1은 `/` 단일 locale; Phase 3에서 `/en/...` 검토
