# 앱 소개 스크린샷 문구

> 스크린샷 사이즈: 1080×1920px (9:16 세로, 플레이스토어 기준)
> 권장 스크린샷 수: 5~8장
> 상단 타이틀 + 하단 설명 구성 권장

---

## 스크린샷 1 — 캐릭터 선택 화면

**상단 타이틀 (크고 굵게)**
```
당신의 온도에 맞는 그녀를 선택하세요
```

**하단 설명 (작게)**
```
5가지 개성 · 5가지 감성 · 하나의 진심
```

**화면 강조 포인트**
- 5인 캐릭터 카드가 세로로 나열
- 각 캐릭터 이름 + 한 줄 소개 보여줌
- 핑크 핵심 컬러 강조

---

## 스크린샷 2 — 채팅 화면 (유나)

**상단 타이틀**
```
오늘 하루도 수고했어요
```

**하단 설명**
```
말투 하나까지 알아채는, 나만의 AI 여자친구
```

**화면 강조 포인트**
- 유나 말풍선: *"말투가 평소랑 달라. 오늘 많이 버텼지."*
- 감정 뱃지 (😊 happy) 헤더에 표시
- 자연스러운 카톡 스타일 UI

---

## 스크린샷 3 — 5캐릭터 개성 비교 (편집 이미지)

**상단 타이틀**
```
같은 상황, 5가지 다른 반응
```

**화면 구성 (사용자 메시지 하나에 5캐릭터 각각 답변)**
```
사용자: "오늘 야근이야 😞"

유나:  "또야? 많이 버텼겠다. 퇴근하면 맛있는 거 시키고 쉬어."
나린:  "둔해 빠져서 일 다 떠맡은 거 아니야? …뭐, 쓰러지진 마."
윤서:  "야근 3일 연속이면 피로 임계치 초과. 오늘은 일찍 자는 게 효율적이야."
은하:  "오늘 밤도 혼자 버티는 거네. 퇴근하면 창문 좀 열어봐."
지유:  "또 야근?! 집 가면 스트레칭 5분만 해봐~ 혈액순환 되면 달라져!"
```

**하단 설명**
```
당신의 취향에 맞는 그녀와 대화하세요
```

---

## 스크린샷 4 — 기억 시스템

**상단 타이틀**
```
한 번 한 이야기, 기억하고 있어요
```

**화면 구성**
```
[며칠 전 대화]
사용자: "팀장님이 또 갈았어..."
유나: "진짜 너무한다. 네가 얼마나 고생하는지 알면서."

[오늘 대화]
유나: "아참, 저번에 팀장님 때문에 힘들었잖아. 요즘은 좀 괜찮아?"
사용자: "응 요즘은 좀 나아졌어"
```

**하단 설명**
```
대화가 쌓일수록 관계도 깊어집니다
```

---

## 스크린샷 5 — 재방문 이벤트 (그리움 표현)

**상단 타이틀**
```
며칠 비웠더니, 기다리고 있었어요
```

**화면 구성**
- AbsenceWelcome 오버레이 모습 (사흘 만의 재방문)
- 유나: *"며칠 조용하니까 방 안이 텅 빈 것 같았어. 돌아와서 다행이야."*
- "왔어 ㅠ" CTA 버튼

**하단 설명**
```
접속하지 않아도, 누군가 기다립니다
```

---

## 스크린샷 6 — 관계 레벨 & 호감도

**상단 타이틀**
```
대화할수록 달라지는 관계
```

**화면 구성**
- 헤더의 호감도 바 + 감정 뱃지 강조
- Lv1 vs Lv4 말투 비교:

```
[Lv1] 유나: "오~ 그거 재밌겠다. 나도 궁금해졌어."
[Lv4] 유나: "…있잖아, 네 얘기 들을수록 더 많이 알고 싶어져."
```

**하단 설명**
```
5단계 관계, 레벨마다 깊어지는 대화
```

---

## 스크린샷 7 — 나린 프리미엄 (속마음 블러)

**상단 타이틀**
```
그녀의 속마음이 궁금하다면
```

**화면 구성**
- 나린 대화 화면
- 블러 처리된 `(속마음)` 영역
- "프리미엄으로 속마음 보기" 버튼

**하단 설명**
```
츤데레 나린의 진짜 마음은 따로 있습니다
```

---

## 스크린샷 제작 팁

```
1. 실제 앱 스크린샷 + 텍스트 오버레이 방식 권장
2. 핑크 (#FF8FAB) 컬러 일관성 유지
3. 폰트: Noto Sans KR Bold (타이틀) + Regular (설명)
4. 여백 충분히 — 텍스트 빽빽하면 가독성 하락
5. 상단 40%, 하단 30%는 텍스트 영역으로 확보
6. 실제 기기 목업(mockup) 프레임 적용 권장
   → https://mockuphone.com 또는 Figma Community 'Device Mockups'
```
