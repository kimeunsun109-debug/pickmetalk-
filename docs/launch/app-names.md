## 플레이스토어 이름 최종 결정 시 고려사항

1. **15자 이내** (구글 플레이 앱 이름 15자 제한)
2. **경쟁 앱과 중복 여부 확인** → 플레이스토어에서 직접 검색
3. **상표 등록 가능 여부** → 특허정보검색서비스(kipris.or.kr)에서 확인
4. **영문 병기** → 해외 사용자 유입 시 `연심 - AI 여자친구` 형식 권장
