# Google Play — 데이터 보안 설문 (초안)

Play Console → 앱 콘텐츠 → **데이터 보안** 작성 시 참고. 법적 최종 책임은 운영자 확인 필요.

## 데이터 수집 여부

**예** — 계정 및 서비스 제공에 필요한 데이터를 수집합니다.

## 데이터 처리

- **암호화 전송:** 예 (HTTPS)
- **사용자 데이터 삭제 요청:** 예 — 앱 설정 → 계정 삭제 (`DELETE /api/account/delete`)
- **데이터 판매:** 아니오
- **데이터 공유:** AI 응답 생성을 위해 **DeepSeek** API로 대화 텍스트 전송 (서드파티 처리). Supabase(Postgres)에 저장.

## 제3자 (데이터 접근)

| 제공자 | 역할 | 데이터 |
|--------|------|--------|
| Supabase | DB·인증 | 계정, 프로필, 메시지 |
| DeepSeek | LLM API | 채팅 메시지(추론) |
| Vercel | 호스팅 | 접속 로그(기본) |

개인정보처리방침: https://pickmetalk.com/privacy
