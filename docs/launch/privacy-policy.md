## 제1조 (개인정보의 처리 목적)

회사는 다음의 목적을 위하여 개인정보를 처리합니다.  
처리하는 개인정보는 다음의 목적 이외의 용도로는 사용되지 않으며,
이용 목적이 변경되는 경우에는 별도의 동의를 받는 등 필요한 조치를 이행합니다.

1. **회원 가입 및 관리** — 본인 확인, 서비스 부정 이용 방지
2. **AI 채팅 서비스 제공** — 사용자와 AI 캐릭터 간의 대화 생성 및 저장
3. **서비스 개선 및 분석** — 사용 패턴 분석, 품질 향상, 베타 테스트 데이터 수집
4. **고객 지원** — 문의 처리 및 불만 해결

## 제2조 (수집하는 개인정보의 항목 및 수집 방법)

### 수집 항목

**필수 항목**

| 항목 | 수집 목적 |
|---|---|
| 이메일 주소 | 회원 가입, 본인 확인, 로그인 |
| 비밀번호 (해시 암호화 저장) | 계정 보안 |

**서비스 이용 중 자동 생성·수집**

| 항목 | 수집 목적 |
|---|---|
| 대화 내용 (AI와의 채팅 메시지) | AI 응답 생성, 대화 맥락 유지, 기억 시스템 |
| 캐릭터 관계 데이터 (호감도, 관계 레벨) | 서비스 기능 제공 |
| 접속 기록 (접속 일시, 이벤트 로그) | 서비스 분석, 재방문 기능, 베타 테스트 |
| 기기 정보 (OS 종류) | 서비스 호환성 유지 |

**수집하지 않는 항목**
- 실명, 전화번호, 주소
- 위치 정보
- 결제 정보 (현재 베타 버전 미적용)

### 수집 방법
- 회원 가입 시 이용자가 직접 입력
- 서비스 이용 과정에서 자동 수집

## 제6조 (개인정보의 파기)

회사는 개인정보 보유 기간의 경과, 처리 목적 달성 등 개인정보가 불필요하게 되었을 때에는 지체 없이 해당 개인정보를 파기합니다.

- **전자적 파일 형태**: 복원이 불가능한 방법으로 영구 삭제
- **회원 탈퇴 처리**: 앱 내 '계정 삭제' 기능 또는 이메일 요청 후 30일 이내 모든 개인정보 삭제

## 제9조 (개인정보의 안전성 확보 조치)

회사는 개인정보의 안전성 확보를 위해 다음과 같은 조치를 취하고 있습니다.

| 조치 | 내용 |
|---|---|
| 비밀번호 해시 처리 | Supabase Auth 내부 bcrypt 해시 저장 |
| 전송 구간 암호화 | HTTPS/TLS 1.2 이상 |
| 데이터 접근 제어 | Row Level Security(RLS) 적용 — 로그인한 본인 데이터만 접근 가능 |
| 서버 인프라 암호화 | Supabase(PostgreSQL) 인프라 수준 저장 암호화 제공 |

> 📌 **주의**: 대화 내용 자체에 대한 애플리케이션 수준의 별도 암호화는 현재 적용되어 있지 않습니다.  
> RLS(Row Level Security)는 접근 제어 정책이며 암호화와는 다릅니다.
